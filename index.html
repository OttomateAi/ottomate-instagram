Connect the planner

The planner needs its own GitHub key to save posts to your repo. It's stored only in this browser.

  1. Go to github.com/settings/personal-access-tokens and click Generate new token.
  2. Name: ottomate-planner. Expiration: No expiration.
  3. Repository access: Only select repositories, then ottomate-instagram.
  4. Permissions: Contents: Read and write and Actions: Read and write.
  5. Generate it, copy it, and paste it below.
